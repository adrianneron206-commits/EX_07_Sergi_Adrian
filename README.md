# Ejercicio 07

Proyecto Java del ejercicio 07.

## Requisitos

- Crear un cuestionario con preguntas de Java y cuatro respuestas posibles por pregunta.
- Disponer de un banco de al menos 50 preguntas.
- Verificar que las preguntas y sus respuestas estén completas y sean correctas.
- Validar que la entrada del usuario sea correcta y corresponda a una de las opciones disponibles.

## Estructura

- `src/Main.java`: archivo principal del ejercicio.

## Como abrirlo

Abre la carpeta del proyecto en IntelliJ IDEA y ejecuta la clase `Main` cuando tenga codigo.
