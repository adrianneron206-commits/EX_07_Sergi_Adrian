# Proyecto: Test de Java (50 preguntas)

Cuestionario interactivo de Java para consola, desarrollado colaborativamente mediante ramas de Git.

## Requisitos

- Crear un cuestionario con preguntas sobre Java y cuatro respuestas posibles por pregunta.
- Disponer de un banco de al menos 50 preguntas.
- Verificar que las preguntas estén completas y que las respuestas sean correctas.
- Validar que la entrada del usuario corresponda a una de las opciones disponibles.
- Interactuar por consola mediante `Scanner` y controlar los flujos y condicionales.
